# Cadence — Mindful Daily Goal & Habit Tracker

> *Mindful discipline over hurried momentum.*

Cadence is a personal daily habit and goal tracking application designed with calm aesthetics, clear daily accountability, and long-term consistency tracking.

---

## 📱 Screens & Features

- **Today (Quiet Mastery):** (`index.html` / `today.html`)
  - Prominent daily date & flow status
  - Daily Spark card with inspirational wisdom & Supabase sync status
  - Today's Alignment progress ring (live percentage calculation)
  - Weekly Rhythm 7-day horizontal cadence
  - Interactive Daily Rituals with 1-tap completion toggles and category filters
- **Nightly Closeout (Seal the Day):** (`closeout.html` / `code.html`)
  - Evening wind-down status banner & streak tracker
  - Review practices with segmented Done/Missed options
  - Daily wind-down reflection box for logging notes on missed goals
  - Bedtime actions ("Seal Day & Activate Sleep Mode")
- **Design Tokens & System:** (`DESIGN.md`)
  - Full color palette, typography guidelines (Plus Jakarta Sans), and elevation tiers.

---

## 🚀 How to Run Locally

You can run Cadence using any simple static HTTP server:

```bash
# Using Python
python -m http.server 3000

# Using Node / npx
npx serve .
```

Then open [http://localhost:3000](http://localhost:3000) in your browser.
